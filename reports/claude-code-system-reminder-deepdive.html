1. Claude Code가 몰래 주입하는 세 가지 가변 텍스트

Claude Code는 사용자가 입력한 프롬프트 외에도, 대화 컨텍스트 후미에 아래와 같은 동적 문자열들을 매 턴 새로 생성하여 끼워 넣습니다.

① totalTokensReminder (카운트다운)
매 턴 남아 있는 세션 토큰 잔량을 모델에 주지시키기 위해 아래 형식의 텍스트를 강제로 주입합니다:
<total_tokens>14931235 tokens left</total_tokens>
매 턴 숫자가 바뀌므로 해시가 무조건 달라집니다.
② 실시간 작업 환경 메타데이터
현재 로컬 시스템 시각, 작업 디렉터리의 실시간 git status 변경 내역, 직전 실행한 bash 명령 결과 요약 등을 직전 메시지 블록에 업데이트하여 전송합니다.
③ 동적 플러그인 / 스킬 디렉티브
현재 활성화된 스킬 목록, 백그라운드 태스크 알림(task-notification) 등을 컨텍스트에 추가 주입합니다.

2. 나비효과: 361바이트의 토큰 카운터 변경이 미치는 영향 (show-me)

직전 턴의 메시지와 새 턴의 메시지를 diff로 비교하면, 단 한 줄의 토큰 카운터 숫자가 바뀐 것뿐입니다.

// 직전 턴의 마지막 메시지 vs 현재 요청의 메시지 비교 (diff) <system-reminder> 현재 작업 디렉터리: /Users/ms/dev/meridian - <total_tokens>14931235 tokens left</total_tokens> + <total_tokens>14926828 tokens left</total_tokens> // <-- 고작 이 361바이트 숫자 변경! </system-reminder>
[증폭 메커니즘 흐름도] 1. Claude Code CLI ──(매 턴 바뀐 total_tokens 주입)──> 2. Meridian Proxy ──(이전 대화 해시 불일치: Stale session detected)──> 3. Fresh Replay 발생 ──(기존 세션 포인터 폐기, 40만 토큰 처음부터 재전송)──> 4. Anthropic API ──(신규 캐시 작성 40만 토큰 × 1.25배 가중 과금 폭탄!)──> 5시간 한도 100% 소진

3. 공식 GitHub 버그 리포트 실측 증거 (Issue #90018)

Anthropic 공식 저장소 anthropics/claude-code의 이슈 #90018에서 보고된 실제 실측 데이터입니다. totalTokensReminder로 인해 캐시 읽기(cache_read)가 바닥(8,192 토큰)에 묶이고 미스된 토큰이 눈덩이처럼 불어나는 현상이 정확히 일치합니다.

요청 순번 미스된 입력 토큰 (Uncached Input) 캐시 읽기 (Cache Read) 주입된 토큰 리마인더 내용
Turn 1 60,327 tokens 8,192 tokens (캐시 바닥) <total_tokens>14931235 tokens left</total_tokens>
Turn 2 63,476 tokens 8,192 tokens (캐시 바닥) <total_tokens>14926828 tokens left</total_tokens>
Turn 3 66,656 tokens 8,192 tokens (캐시 바닥) <total_tokens>14923572 tokens left</total_tokens>
Turn 10 77,252 tokens 8,192 tokens (캐시 바닥) 매 턴 숫자가 바뀌며 캐시가 누적되지 못함
로컬 바이너리(v2.1.258) 내부 추출 문자열:
<(system-reminder|task-notification)>[\s\S]*?(<\/\1>|$) system_reminders_count system_reminders userSystemPrompt critical_system_reminder
